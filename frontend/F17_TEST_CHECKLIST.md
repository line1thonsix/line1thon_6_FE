# F-17 최근 대화·학습 기록 검증

## 범위와 실행

React UI + 개발 MSW 환경에서 확인했습니다. 실제 API 연결, 서버의 게스트 인증/권한, 영구 저장, F-18 삭제는 이번 범위가 아닙니다. 문서 원본은 수정하지 않았습니다.

```sh
cd frontend
npm run dev:mock
npm run build
npm run lint
npm test
```

Vite가 출력하는 주소를 사용합니다. 이번 브라우저 검증 주소는 `http://127.0.0.1:5174/`, PC 레이아웃 기준은 1440×900입니다. 각 URL은 **같은 탭**에서 이동해야 Mock 대화/초안/회고가 유지됩니다. 새 탭에서는 빈 기록으로 시작합니다.

Figma PC `12 · 학습 기록 목록`(165:830), `12-1 · 학습 기록 (카드에 마우스 커서 올림)`(332:1600), `12-2 · 학습 기록 없음`(171:836)을 대조했습니다. 사용자 확인에 따라 화면 태그는 ‘비교 완료 / 기초 학습’, 내부 경로는 SELF / BASIC을 유지합니다.

## 시연 옵션과 실제 연동 시 확인할 사항

- `history=slow`: 약 5초 목록 지연. `history=error`: 계속 실패. `history=error-once`: 첫 조회만 실패(새로고침하면 다시 첫 실패).
- `analysis=slow`, `analysis=always-fail`, `mock=slow`는 기존 개발 Mock 옵션입니다. 기존 질문/분석 시나리오는 그대로 유지합니다.
- 개발 환경의 기존 `MSW Mock · 실제 AI 미연결` 안내로 Figma보다 본문이 아래로 내려갑니다. 운영 빌드에는 이 안내가 없습니다.
- 목록의 더보기 점은 Figma 원본 장식 아이콘입니다. 삭제/이름 변경 메뉴를 새로 구현하지 않았습니다. 키보드 강조는 hover와 같은 디자인 토큰을 사용하며, 실제 마우스 hover 조작은 별도 수행하지 않았습니다.
- 실제 백엔드 연동 전 GET 목록 DTO/인증/소유권/정렬 기준·시간대/페이지네이션과 서버 회고 저장 계약을 합의해야 합니다. 현재 `/api/chats` 목록은 임시 Mock 계약이며 운영에서 Mock 요청을 보내지 않도록 차단합니다.
- Mock 데이터는 기존과 같이 탭의 sessionStorage에 보관됩니다. 영구 저장이나 실제 서버의 소유권 검증을 대신하지 않습니다.
